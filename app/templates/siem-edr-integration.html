How TIP Amplifies EDR & SIEM

  • 1. Alert Ingestion: Your EDR (CrowdStrike / Defender) or SIEM (Splunk / Sentinel) posts an alert when suspicious activity triggers.
  • 2. Auto-Extraction: TIP automatically parses IPv4 addresses, domains, URLs, and MD5/SHA256 hashes from the alert payload.
  • 3. Risk Scoring & Correlation: TIP checks external reputation (AbuseIPDB, VirusTotal, OTX) and correlates against past reports and known malware families.
  • 4. Alert Generation: If an indicator exceeds risk thresholds (score ≥ 75 CRITICAL or 50–74 HIGH), an incident is prioritized immediately in the Alert Center.
  • 5. Sensor Blocklist: Firewalls and EDR custom IOC lists consume the /feed/blocklist/plain endpoint to preemptively block bad actors.

Vendor Ingestion Payloads

Example cURL webhook call from Splunk / Sentinel:

curl -X POST "{{ host_url }}/api/v1/webhook/alert" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "title": "Suspicious C2 Beacon Detected",
    "source": "Splunk ES",
    "severity": "Critical",
    "description": "Connection to 185.10.10.10:4444",
    "iocs": ["185.10.10.10", "c2-domain.org"]
  }'

Dedicated EDR Alert & Telemetry Ingestion (CrowdStrike / Defender):

curl -X POST "{{ host_url }}/api/v1/edr/alert" \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "hostname": "FINANCE-WS01",
    "host_ip": "10.0.4.15",
    "vendor": "CrowdStrike Falcon",
    "DetectionName": "Cobalt Strike Beacon In-Memory Execution",
    "Severity": "Critical",
    "FileName": "powershell.exe",
    "ProcessId": 4812,
    "CommandLine": "powershell.exe -enc aW52b2tlLW1pbWlrYXR6 -c2 185.10.10.10",
    "SHA256": "44d88612fea8a8f36de82e1278abb02f44d88612fea8a8f36de82e1278abb02f",
    "MitreTechniques": ["T1059.001", "T1071.001"]
  }'

Real-time SIEM IOC Lookup Query:

curl -X GET "{{ host_url }}/api/v1/ioc/lookup?indicator=185.10.10.10" \
  -H "X-API-Key: YOUR_API_KEY"

Export Threat Intelligence as OASIS STIX 2.1 Bundle (MISP / OpenCTI):

curl -X GET "{{ host_url }}/api/v1/stix/bundle?min_risk=50" \
  -H "Accept: application/vnd.oasis.stix+json; version=2.1"
